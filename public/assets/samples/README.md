# Drum Samples

This directory should contain the following audio files:

- `kick.wav` - Kick drum sample
- `snare.wav` - Snare drum sample  
- `hihat.wav` - Hi-hat sample
- `clap.wav` - Clap sample

These samples are loaded by the DrumEngine in `src/features/drums/lib/drum-sampler.ts`.

## Sample Requirements

- Format: WAV or compatible audio format
- Mono or stereo
- Sample rate: 44.1kHz recommended
- Bit depth: 16-bit or 24-bit recommended

## Adding Samples

Place your sample files in this directory with the exact names listed above.
